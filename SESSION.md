adjoining Myanmar–Bengal margin**, 1934–2026, plus a research-gap analysis. Built for
Tapaswi (saikiatapaswi2025@gmail.com), whose PhD work is on IBR seismology.

## Pipeline — saved and runnable

**`~/all_papers/IBR/_scripts/`** holds the whole pipeline plus every intermediate JSON in
`_scripts/data/`, so the common tasks need no network. See `_scripts/README.md`.

```bash
cd ~/all_papers/IBR/_scripts
python3 export.py    # regenerate CSV + Markdown      (offline, instant)
python3 gen.py       # regenerate ../ibr.html         (offline, instant)
```

Edit `gaps.py` to change the 17 method gaps **or their ranking** (the `RANK` dict at the bottom,
keyed by gap name; two asserts catch a typo or a duplicate rank); edit the quartile sets in `merge2.py`
to correct a Q-rating, then rerun `merge2.py` → `gen.py` → `export.py`.

Full rebuild (only when `~/all_papers/cards/` changes; hits CrossRef, ~20 min):
`enrich.py` → `build.py` → `patch.py` → `merge.py` → `rescue.py` → `sweep.py` → `merge2.py`
→ `gen.py` → `export.py`. Both `gen.py` and `merge2.py` were verified to reproduce the
current output exactly (verified at 634 entries in session 1; the file they now read is
`final3.json`, 895 entries after the off-topic prune). `merge3.py` rebuilds `final3.json` offline
from `sweep_oa.json` + `sweep_ctx.json`, so re-running the prune costs nothing.

## Decisions and corrections made (do not re-litigate)

- **Strictly chronological, one list.** User rejected topic sections explicitly. (This governs the
  bibliography only — the *gap* list is ordered by rank, see below.)
- **Year bars are clickable** (session 2). Each non-empty bar is a `<button>`; clicking filters the
  list to that year, clicking more bars adds years, and the bars mute to show how much of each year
  survives the search/tag filters. Bar heights deliberately ignore the year filter itself — otherwise
  selecting one year flattens the other 92 and destroys the context you clicked into.
- **The 17 gaps are ranked 1–17** (session 2), interleaving the three tracks; each card carries a
  rank badge, a track chip and a "Why this rank" line, and a "Start here" box names the first
  experiment. Axis: startable-with-what-you-have × novelty × consequence, ties broken towards work
  that unlocks lower-ranked items; **assumes no field budget and no ship time**. Ranks 14–17 (DAS,
  nodal array, trenching, OBS) are blocked by money and permissions, not by science.
- **Off-topic sweep results pruned** (session 2, at the user's request — they spotted a Dutch
  slave-trade paper at #889). The OpenAlex context sweep matched on abstracts alone and pulled in
  arsenic hydrochemistry, monsoon/cyclone meteorology, a mollusc description and several humanities
  and policy papers. `merge3.py` now gates context entries with a `GEO` (must read as earth science)
  and `OFF` (must not be an off-topic subject) pair of regexes: **953 → 895**, 58 removed, listed in
  `data/dropped_offtopic.txt`. Never applies to `scope='focused'` or to library-held PDFs. Three
  false positives are rescued by DOI in `RESCUE` (Andaman Sea provenance caught by "monsoon
  variability"; Cox's Bazar landslide geology caught by "Rohingya" in the camp name; Yangon ground
  information). **If more junk turns up, extend `OFF` or `RESCUE` in `merge3.py`, then rerun
  `merge3.py` → `gen.py` → `export.py`.**
- **Filter bug, fixed:** the original regex required "Indo-Burma"/"Burmese"/"Myanmar" and missed
  plain **"Burma"**, dropping Fitch 1972, Westerweel 2019 (*Nat. Geosci.*) and 16 others.
- **Unicode-hyphen bug, fixed:** CrossRef returns U+2010 in "deep‐learning", which hid Yang 2024.
  Normalise dashes before any keyword tagging.
- **Wrongly dropped, restored:** Khin et al. 2022 (*Geosystems and Geoenvironment*,
  `10.1016/j.geogeo.2022.100079`) — its truncated DOI had matched that journal's launch editorial.
- **Excluded deliberately:** ~14 b-value papers from other regions (ZMAP, California, Italy, Red
  Sea, NW Himalaya); generic ML method papers with no regional link; the user's own generated
  notes and summaries; conference abstracts.
- **Scimago is Cloudflare-blocked.** Quartiles are assigned from journal-level knowledge, not a
  live pull. Unknown journals are marked `unrated` rather than guessed. **Always repeat this
  caveat** — the user may quote these in a submission.

## Method-gap analysis — 17 openings

Three tracks (Seismology / AI-ML / Hazard), interleaved by rank on the page. Each absence was **verified by CrossRef query**, not
assumed. Confirmed zero regional hits: slow slip & tremor, DAS, full-waveform inversion, OBS on
the Bengal margin, transformer phase picking.

Ten need only the existing archive. Ranked order of the top three (see the `RANK` dict in `gaps.py`):
1. **Modern b-value estimators** (b-positive, b-significant; Mirwald/Mizrahi 2024 *SRL* and
   van der Elst 2021, both in the library) — all 28 regional b-value papers use
   maximum-curvature/MLE with no significance test. Laptop-scale, inside the user's own thesis
   topic. This is the "Start here" experiment on the page: re-run the claimed spatial and temporal
   b-anomalies for 22–28° N, 90–96° E, 1964–2025 and report which survive a significance test.
2. **Deep-learning phase picking** on the NE India archive — the user owns PhaseNet,
   EQTransformer, SeisBench, GaMMA, PyOcto and has applied none of them regionally.
   Yang 2024 (*GRL*) doubled the catalog this way in central Myanmar. Ranks 3, 6 and 8 build on it.
3. **Matched-filter catalogue extension** — same archive, existing catalogue as templates, CPU not
   GPU, and an independent cross-check on the DL catalogue. (Slow slip / tremor is rank 4: highest
   ceiling, but a null result is a real possibility.)

Recurring theme: **the library is full of method papers from elsewhere never turned on the
user's own region** (matched filtering has been applied to *Mars* in this library, never to IBR).

## Known limits

- CrossRef misses pre-1990 Indian literature without DOIs (*MAUSAM*, *Current Science*, *JGSI*
  are thin). Full historical coverage needs a hand search.
- Absence of a DOI-indexed paper is not proof nobody tried — check theses and grey literature
  before writing a proposal on any gap.
